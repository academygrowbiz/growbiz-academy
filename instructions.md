# GrowBiz Academy

This is the GrowBiz Academy website.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

## Structure
- Next.js project using `src/`
- Static assets are in `public/`
- Course pages use dynamic routes
- Main course routes are under `/courses`

## Design
- Modern dark learning-platform UI
- Dark navy/black background
- Purple accent
- White headings
- Muted secondary text
- Rounded cards and buttons
- Clean SaaS/education aesthetic

## Rules
- Reuse existing components and styles where possible.
- Do not redesign completed pages unnecessarily.
- Do not change the project architecture unless required.
- Use TypeScript.
- Use Tailwind CSS for styling.
- Use existing shadcn/ui components where appropriate.
- Keep responsive behavior for desktop and mobile.
- Before creating a new component, check whether an existing component can be reused.
- Keep implementations simple and maintainable.
